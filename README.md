# Lastverschiebung in einem Heizungssystem

Code, Ergebnisse und Promptverzeichnis zur Maturaarbeit «Lastverschiebung in einem Heizungssystem»,
Gymnasium Münchenstein, 2026.

## Inhalt

- [`Simulation/`](Simulation/): Simulation der Heizungsanlage mit Wärmepumpe und Pufferspeicher, die
  untersuchten Regelstrategien, die Ergebnisse der Arbeit und die trainierten RL-Modelle.
  Einrichtung und Benutzung sind im [README der Simulation](Simulation/README.md) beschrieben.
- [`Promptverzeichnis/`](Promptverzeichnis/): die Prompts der KI-Werkzeuge, die im KI-Verzeichnis der
  Arbeit zusammengefasst sind.

Der Tag `v1.0-abgabe` entspricht dem abgegebenen Stand.
